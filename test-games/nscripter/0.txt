; Enginehost conformance test game for the nscripter plugin.
;
; MIT licence -- test-games/LICENSE.  Plain ASCII, so the same script runs
; with the engine's sjis, gbk and utf8 script encodings alike.  It
; exercises: text that redraws the window on every click (the frame that
; changes), click waits and a select menu (the input response), and
; savegame 1 (a save in the engine's own save directory, wherever
; Enginehost mapped it).  See docs/conformance-test-games.md.

*define
clickstr"?!."
game

*start
This is the Enginehost conformance test game.
A click here redraws the window with new text, which is the frame changing.
click
The next step is a choice. Press to continue.
click
select "Save the game", *save, "Exit without saving", *end

*save
savegame 1
The game saved into the engine's own save directory, wherever Enginehost mapped it.
click
end

*end
No save was written. Closing the window here is a clean end.
click
end
