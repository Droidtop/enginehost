; Enginehost conformance test game for the nscripter plugin.
;
; MIT licence -- test-games/LICENSE.  Plain ASCII, so the same script runs
; with the engine's sjis, gbk and utf8 script encodings alike.  It
; exercises: the first click turning the black background blue (the frame
; changing on input, large enough to see on any screen: a new line of text
; alone changed 1% of an emulator's), and then every further click writing
; savegame 1 (a save in the engine's own save directory, wherever
; Enginehost mapped it), so a save is one click whatever came before it.
; See docs/conformance-test-games.md.
;
; Each line of text starts with a backquote: NScripter reads a line that
; starts with an ASCII letter as a command, and without the backquote the
; first sentence was "command [this] is not supported yet!!" and nothing
; was ever drawn.

*define
clickstr"?!."
game

*start
`This is the Enginehost conformance test game.
bg #3a5f9a,1

*loop
`Each click from here saves the game to slot 1\
savegame 1
goto *loop
